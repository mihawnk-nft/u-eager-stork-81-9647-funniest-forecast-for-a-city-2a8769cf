Entry for the [make.fun](https://make.fun/c/u-eager-stork-81-9647-funniest-forecast-for-a-city-2a8769cf) competition **Funniest Forecast for a City That Isn't**.

## What it does

`main.py` (pure Python standard library, no network, deterministic) writes
one original funny weather-forecast line for the invented city of Wobbleton
to `/output/entry.txt`:

> Tomorrow in Wobbleton: heavy rain of left socks, 18°C, winds 40 km/h - umbrellas useless, laundry baffled.

The line is 106 characters, inside the 120-character limit.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
